This website is hosted via GitHub Pages. When you visit this site, GitHub may process technical server log data (such as IP address, browser type and access times) as part of standard hosting operations. Contact form

The contact form on this website is designed to be processed via Formspree, a third-party form-handling service. This paragraph applies once the form is activated: submitted data (such as name, email and message content) is transmitted to and processed by Formspree in order to deliver your enquiry to Byzaro Group. Until activation, the form operates in a local demonstration mode and no data is transmitted anywhere.

Fonts

All fonts used on this website are hosted locally. No font files or related data are requested from Google Fonts or any other external font provider.

Local storage (localStorage / sessionStorage)

This website uses your browser’s localStorage to remember (1) your preferred color theme (light/dark) and (2) on the homepage, which of the rotating headline claims was shown last (so the same one doesn’t appear twice in a row). It also uses sessionStorage to show the logo intro animation only once per browser session. All of this is purely functional, contains no personal data and is not used for tracking.

Cookies & Tracking

This website does not set cookies and does not use analytics, advertising or tracking tools of any kind.

Your rights
