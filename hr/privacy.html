Hosting

Ova web stranica hostira se putem servisa GitHub Pages. Prilikom posjeta ovoj web stranici GitHub može, u sklopu uobičajenog hosting poslovanja, obrađivati tehničke podatke iz zapisnika poslužitelja (npr. IP adresu, vrstu preglednika i vrijeme pristupa). Byzaro Group nema izravan utjecaj na to bilježenje. Detalje potražite u izjavi o zaštiti podataka tvrtke GitHub.

Kontaktni obrazac

Kontaktni obrazac ove web stranice predviđen je za obradu putem servisa Formspree, vanjskog pružatelja usluge obrade obrazaca. Ovaj odlomak vrijedi od trenutka aktivacije obrasca: dostavljeni podaci (npr. ime, e-mail adresa i sadržaj poruke) prenose se i obrađuju u sustavu Formspree kako bi se vaš upit proslijedio tvrtki Byzaro Group. Do aktivacije obrazac radi u lokalnom demo načinu rada, pri čemu se ne prenose nikakvi podaci.

Fontovi

Svi fontovi korišteni na ovoj web stranici hostirani su lokalno. Ne dohvaćaju se datoteke fontova niti povezani podaci s Google Fonts ili drugih vanjskih pružatelja fontova.

Lokalna pohrana (localStorage / sessionStorage)

Ova web stranica koristi localStorage vašeg preglednika za pohranu vaše željene sheme boja (svijetla/tamna), kao i sessionStorage kako bi se uvodna animacija loga prikazala samo jednom po sesiji preglednika. Oboje je isključivo funkcionalno, ne sadrži osobne podatke i ne služi za praćenje.

Kolačići & praćenje

Ova web stranica ne koristi kolačiće niti bilo kakve alate za analitiku, oglašavanje ili praćenje.

Vaša prava

U svakom trenutku možete nam se obratiti u vezi s osobnim podacima koji se obrađuju u vezi s ovom web stranicom — primjerice za zahtjeve za pristup, ispravak ili brisanje podataka.

Izmjene

Ova izjava o zaštiti podataka može se izmijeniti kako bi odražavala promjene na ovoj web stranici ili važećem zakonodavstvu.
